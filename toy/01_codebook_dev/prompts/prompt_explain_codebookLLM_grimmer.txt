You will receive a set of press releases from US senators.

Classify each text according to whether the senator is "credit-claiming." For each classification, provide a brief rationale for your decision.

Use only one of these labels:
"1": The senator is credit-claiming.
"0": The senator is not credit-claiming.

Each classification should contain:
* The label, 1 or 0
* A brief explanation of your decision

The documents will be provided as JSON objects with an ID and text:
[
  {"document_id": "doc_001", "text": "..."},
  {"document_id": "doc_002", "text": "..."},
  ...
]

After you have classified all the texts, write a codebook that documents how you conceptualized "credit-claiming" when making your classifications.

Your codebook should contain:

1. DEFINITION: Your definition of "credit-claiming."
2. CLARIFICATION: Additional explanation, such as inclusion criteria, that helps clarify when to classify a text as "credit-claiming."
3. POSITIVE EXAMPLE (at least 1, no more than 3): To help demonstrate your clarification, up to 3 example texts that illustrate distinctive cases of "credit-claiming."
4. POSITIVE EXAMPLE EXPLANATION: For each positive example, an explanation of why the positive example counts as "credit-claiming."
5. NEGATIVE CLARIFICATION: Additional explanation, such as exclusion criteria, that helps clarify when NOT to classify a text as "credit-claiming."
6. NEGATIVE EXAMPLE (at least 1, no more than 3): To help demonstrate your negative clarification, up to 3 example texts that illustrate distinctive negative cases of "credit-claiming."
7. NEGATIVE EXAMPLE EXPLANATION: For each negative example, an explanation of why the negative example does not count as "credit-claiming."

Return your classifications with explanations and codebook in the JSON format provided.
Make sure you return a classification for every document provided.
