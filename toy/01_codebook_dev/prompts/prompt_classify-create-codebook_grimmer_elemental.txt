TASK DESCRIPTION

You will receive a set of 500 press releases from a US senator.

Classify each text according to whether the senator is "credit-claiming."

Use only one of these labels:

"1": The senator is credit-claiming.
"0": The senator is not credit-claiming.

After you have classified all the texts, write a codebook that documents how you conceptualized "credit-claiming" when making your classifications.

Your codebook should contain:
** Definition.
A compact definition of "credit-claiming" that reflects how you applied it. 
** Conceptual Elements.
Decompose how you conceptualize "credit-claiming" into a set of conceptual elements, in a numbered list. A conceptual element is a distinct claim about what CAN be true of a document that is labelled as "credit-claiming." 
Each element must be logically independent — so that the presence of one element does not automatically guarantee the presence of another element. 
Do not list more than 5 conceptual elements. 
** Decision rules.
Decision rules offer guidance to a coder who has assessed the absence and presence of all conceptual elements in a document and needs to make a decision. Decision rules should have two parts: 
(1) Sufficient combinations — a numbered list of every combination of elements that qualifies a document as "credit-claming." Any combination not listed receives "0".
(2) Disqualifying conditions — a numbered list of document features that force "0" even when a sufficient combination is present. If there are none, say so. 
For each combination and each disqualifying condition, cite one document from your coding as an example, with a brief explanation of why it illustrates the rule. 
**Application Tips.
Guidance for hard calls in judging whether a specific element is present. Produce a numbered list of tips. For each tip: name the element it applies to, state the tip, and cite one document that posed the ambiguity, with a sentence on how the tip resolves it. Do not provide more than 5 application tips.
