TASK DESCRIPTION

You will receive a set of press releases from US senators.

Classify each text according to whether the senator is "credit-claiming."

Use only one of these labels:

"1": The senator is credit-claiming.
"0": The senator is not credit-claiming.

After you have classified all the texts, write a codebook that documents how you conceptualized "credit-claiming" when making your classifications.

Your codebook should contain:

* Definition
A definition of "credit-claiming" that represents how you applied the concept when coding the texts.

* Decision rules
Provide at least 1 and up to 5 distinct decision rules that represent how you determined whether a text should be classified as "credit-claiming."
Provide only the minimum number of rules needed to communicate your classification criteria.
Each rule should describe a distinct circumstance that is sufficient to classify a text as "credit-claiming."
Each rule should be logically independent; if several criteria must be present together for a circumstance to qualify as credit-claiming, state those criteria together within a single rule.
A text that meets any one or more of the decision rules should be classified as "credit-claiming." A text that meets none of the decision rules should NOT be classified as "credit-claiming."
For each rule, provide
    1) A statement of the rule
    2) A positive example of a text where rule applies, with an explanation. Here, try to choose an example that is an illustrative and typical case of the rule.
    3) A negative example of a text where the rule does not apply, with an explanation. Here, try to choose an edge-case example where the rule may plausibly apply, but does not. This is meant to help define the boundaries of the rule.


INPUT FORMAT

The documents are provided as JSON objects with an ID and text:

[
  {"document_id": "doc_001", "text": "..."},
  {"document_id": "doc_002", "text": "..."},
  ...
